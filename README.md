# Ritesh Khokle Portfolio

A modern personal portfolio website built for showcasing software development work, technical skills, projects, experience, and contact information. The site is designed as a polished single-page experience with a dark mode aesthetic, animated background effects, responsive layout, and strong visual branding.

## Live Demo

Open the site locally in a browser or deploy it to a static hosting platform such as Vercel.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Responsive design
- Animated UI effects
- Static hosting ready

## Features

- Responsive portfolio layout
- Dark/light theme toggle
- Hero section with profile image and CTA buttons
- About, skills, projects, and experience sections
- Featured project cards and social links
- Resume download button
- Clean, modern glassmorphism-inspired UI

## Run Locally

Because this is a static website, you can run it with any local web server.

### Option 1: Python

```bash
cd "c:/Users/prite/OneDrive/Documents/portfolio web"
python -m http.server 8000
```

Then open:

```bash
http://localhost:8000
```

### Option 2: Open directly

You can also open `index.html` directly in a browser, although a local server is recommended for consistency.

## Customization

Update the following files to personalize the portfolio:

- `index.html` — content, sections, links, text, metadata
- `style.css` — layout, colors, spacing, styling
- `main.js` — animations, interactions, theme behavior
- `profile.jpg` — your photo
- `resume.pdf` — your resume

## Deployment

This repository is configured for Vercel deployment through `vercel.json`.
